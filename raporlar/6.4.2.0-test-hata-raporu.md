## 3. Hata ve eksik bulguları

### BUG-642-001 — Bozuk yerel koleksiyon verisi kişisel merkezi runtime hatasına düşürüyor

**Öncelik:** Yüksek  
**Alan:** Kişisel merkez / localStorage dayanıklılığı  
**Durum:** Açık, düzeltilmedi

#### Yeniden üretim

1. Tarayıcı localStorage’ına aşağıdaki değeri yaz:

```json
{"collection":"not-an-array"}
```

Anahtar:

```text
tentiforapp_642
```

2. Sayfayı yenile.
3. “Kişisel merkez” butonuna bas.

#### Gözlenen sonuç

Panelin render akışı şu hataya düşüyor:

```text
TypeError: collection.map is not a function
```

#### Beklenen sonuç

Bozuk veya manipüle edilmiş yerel veri güvenli varsayılanlara dönmeli; panel açılmaya devam etmeli ve koleksiyon boş kabul edilmeli.

#### Etki

Kullanıcı localStorage’ı temizlemeden kişisel merkezi kullanamayabilir. Veri yalnızca cihaz tarafında olsa da kullanıcı deneyimi ve hata toleransı açısından önemlidir.

---

### BUG-642-002 — Evrensel arama paneli yalnızca evrenleri arıyor

**Öncelik:** Orta  
**Alan:** Evrensel arama  
**Durum:** Kısmi özellik, düzeltilmedi

#### Gözlenen durum

Panel “Evren, karakter veya içerik ara” metnini gösteriyor; ancak 6.4.2 modülündeki arama indeksi yalnızca:

- `fanEserleri.evrenler`
- `kanonEvrenleri`

içeriklerinden oluşturuluyor.

Karakter, bölüm, belge, oyun veya kullanıcı kayıtları bu panelin arama indeksine eklenmiyor.

#### Beklenen sonuç

Arama paneli en azından aşağıdaki türleri ayrı etiketlerle desteklemeli:

- Evren
- Karakter
- Bölüm/okuma içeriği
- Belge
- Oyun
- Public kullanıcı/profil

#### Etki

Arama arayüzü kullanıcıya vaat ettiği “evrensel” kapsamı henüz karşılamıyor. Mevcut ana arama sistemi ayrı çalışıyor olabilir; bu bulgu özellikle yeni 6.4.2 kişisel merkezindeki arama paneline aittir.

---

### BUG-642-003 — 6.4.2 web build’i eski ve debug imzalı APK’yı paketlemeye devam ediyor

**Öncelik:** Yüksek — release riski  
**Alan:** APK/web dağıtım senkronizasyonu  
**Durum:** Önceki doğrulamadan devam ediyor, düzeltilmedi

#### Gözlenen durum

6.4.2 web build’i `uygulama/indir/tentiforapp.apk` dosyasını `dist` içine kopyalıyor. APK içinde:

```json
{
  "surum": "6.3.16"
}
```

mevcut.

Beklenen web sürümü:

```text
6.4.2.0
```

APK imzası:

- v1/CMS imzası: geçerli
- Sertifika: `Android Debug`
- v2/v3 signing block: yok
- APK sertifika SHA-256:

```text
9F:72:48:4A:42:ED:E3:A7:C1:0F:EC:5C:0D:5C:93:7E:B4:90:32:24:60:D6:0C:22:B5:9D:13:FF:A6:59:F2:83
```

Bu parmak izi `assetlinks.json` içindeki allowlist parmak izleriyle eşleşmiyor.

#### Beklenen sonuç

6.4.2 release paketi ya:

1. 6.4.2.0 içerikli ve release sertifikalı yeni APK üretmeli, ya da
2. APK/web paketleme ayrımını açıkça uygulamalı ve eski APK’yı production web dağıtımına kopyalamamalı.

#### Etki

- 6.4.2 release arşivinde eski APK bulunuyor.
- Android App Links doğrulaması bu APK ile başarısız olabilir.
- Debug imzalı APK production dağıtımı için uygun değil.
