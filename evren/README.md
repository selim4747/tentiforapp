# Tentiforverse evren dosyaları

Bu klasör GitHub deposundaki evren, hikâye ve ilgili içerik paketleri içindir.

- Yeni dosyalar uygulama içinden GitHub Contents API ile bu klasöre yazılır.
- `evrenler/` altındaki eski dosya yolları geriye dönük uyumluluk için okunmaya devam eder.
- Taslak içerik burada tutulur; moderatör onayından sonra yayın akışına alınır.
- GitHub deposu private olduğu için site ziyaretçileri bu dosyaları doğrudan göremez.
